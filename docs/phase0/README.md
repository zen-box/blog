# 阶段 0 验收记录

2026-10-01。本次完成阶段 0 的细节检查、图表兼容和导入整理。沿用现有组件、暖色配色、阅读宽度和动画；没有开始阶段 1 及后续功能。

验收时截取了 25 种页面的桌面／手机、亮色／暗色对照，截图来自临时演示数据。截图只留在本地，没有放进仓库。

## 环境与覆盖范围

- 生产构建：Next.js 16.3.6，Webpack，standalone，执行项目 postbuild。
- 浏览器：Playwright Chromium；桌面 1440 × 1000，手机 390 × 844（触摸模拟）。
- 页面矩阵：24 条前后台路由 × 4 种视口／主题组合，共 96 次检查；另补齐登录页的 4 种组合。
- 可访问性：axe 的 WCAG 2 A／AA 与 WCAG 2.1 AA 规则。截图和扫描前等待字体、视口入场动画完成；不取消产品动画。
- 所有数据库、演示账号、故障模拟和文章重渲染均在会话临时目录进行；没有修改实际 `data/`。

| CSV／ECharts 图表缺少统一的放大查看                          | 接入原有 SVG 查看器及动画，支持按钮缩放、拖动和手机双指缩放；Markmap 保持交互挂载                                     |

| 缺少统一加载和页面错误提示                                   | 前后台加载提示、错误说明、重试和返回入口；实际延迟导航及临时数据库故障恢复验证                                        |

## 验证结果

- 生产构建、TypeScript、ESLint、Prettier 和 `git diff --check` 通过。
- 96 次页面矩阵：无页面运行时错误、无整页横向溢出，字体均为 `loaded`；axe 0 违规。
- 登录页桌面／手机、亮色／暗色 4 次补测：HTTP 200、axe 0 违规。
- 图表回归命令：`npm run check:diagrams`。覆盖 5 种数据图、CSV／Markdown 表格错误行、JSON5 偏移、Mermaid／Markmap 输出、数据表语义和错误源码转义，包含未闭合 Mermaid 节点的 EOF 回归。
- 桌面拖动、手机 CDP 双指缩放、视口外延迟渲染／预留高度、主题切换后的图表重绘、减少动态效果设置通过补测。
- 空状态：首页无文章、媒体库无文件；错误状态：前台和后台查询失败后恢复数据库，“重试”可重新加载。
- 实际站内导航延迟时可见加载状态。404 提示和返回入口正常，包含 `noindex`；流式响应已发出头部时 HTTP 可能为 200。
- 导入整理：引用图片、平台链接卡片、Mermaid 标签、未知标签提示、代码块保护、重复整理幂等性通过。既有 386 行报告的图片／终端渲染、旧缓存重渲染也通过。

图表完整交互复验：桌面／手机两组均通过，每组覆盖 7 个有效图表的放大入口、数据图缩放、弹窗焦点限制、滚动状态恢复、关闭后焦点返回、图表／表格切换、Mermaid EOF 错误行高亮、Markmap 全屏缩放。EOF 修复后重新生产构建并定向复验这些交互；页面矩阵结果取此前已通过的同一布局版本。

本次 Chromium 验证 `line-break: strict`、`text-autospace: normal`、`text-spacing-trim: trim-start` 生效。`hanging-punctuation` 在该浏览器不支持，会按普通标点排版退化；其他浏览器依其支持程度使用这些渐进增强规则。
