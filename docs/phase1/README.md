## 使用说明

在后台设置的「AI 写作助手」保存协议、基础接口地址、主模型／快速模型及 Key；「保存并测试连接」会调用一次短响应。预设地址和模型可以修改。MiMo 默认主模型 `mimo-v2.6-pro`、快速模型 `mimo-v2.6-flash`。本机／局域网服务可不填 Key；公网服务需 Key。代理使用现有链接卡片出站代理设置，失败不回退直连。

编辑器点击「AI 助手」或 Ctrl／⌘ + J。选择正文后浮出改写工具条，Tab 接受、Esc 放弃，接受后一次 Ctrl／⌘ + Z 撤回。全文建议应用前保存快照，按小节审阅或整体应用；沿用原 Markdown 预览，手机通过现有预览切换查看。文章设置中的「AI 生成文章信息」仅生成建议，勾选字段后填入。

「历史」显示最近 50 个快照和词语差异。恢复前保存当前编辑内容，恢复后填回草稿；不会直接发布。自动保存仅合并连续 auto 的五分钟窗口，手动保存、AI 和恢复形成独立边界。日用量按 UTC 日期记录调用尝试，失败／中断也计数；未报告的 token 不估算。
